  • cleaned_dataset_haug.zip — Roboflow lp-det-v3-job3 + augmentation。total 12,320 影像（unique base 約 3,080，4× hue augmentation _h120/_h140/_h160）。

2. 合併策略對比（5 個方案）

A. 直接合併 — 兩 split 各自 cat 不建議

haug train + 我的 train → 15,443，同樣 valid。

  • 優：實作最簡單 (一個 cp/symlink)。
  • 缺：haug 的 4× hue augmentation 已佔 train 71%，新資料只佔 29% — 不平衡。 ultralytics 訓練時還會自己疊 hue augmentation，等於 hue 被學了 4× 二次，可能 overfit。

B. haug 去 augmentation 後合併 中等

過濾掉檔名含 _h120/_h140/_h160 的 augmentation 變體，只留 base image。train = 2,750 + 4,459 = 7,209。

  • 優：平衡。ultralytics 內建 augmentation 已足夠，不需手動預生成。
  • 缺：放棄 haug 的「免費」augmentation 收益。要重生成 dataset。

C. 兩階段訓練 高品質但慢

# Stage 1: 用 haug 從 yolo26n-pose.pt 訓練（重現原始訓練）
yolo pose train model=yolo26n-pose.pt data=haug/data.yaml epochs=50 ...
# Stage 2: 用 stage1 best.pt 再 fine-tune，只看新資料
yolo pose train model=stage1/best.pt data=yolo26n_ftn_dataset/dataset.yaml \
  epochs=20 lr0=0.0001 freeze=10 ...
  • 優：知識保留乾淨：base 知識 → haug；弱點修正 → 新資料。可獨立評估每階段。
  • 缺：訓練時間倍增。Stage 2 lr 設太大會 catastrophic forgetting。

D. multi-path data.yaml（ultralytics 原生支援） 簡潔

不實體合併檔案，data.yaml 直接列多個 train/val 路徑：

path: /home/itemhsu/amtk/lppart/lp/lp_viewer_tool/lp_viewer_output
train:
  - merged_train_haug_no_aug   # haug 去 aug 後 symlink
  - yolo26n_ftn_dataset/images/train
val:
  - merged_val_haug_no_aug
  - yolo26n_ftn_dataset/images/val

kpt_shape: [4, 3]
flip_idx: [0, 1, 2, 3]
names:
  0: license_plate
  • 優：不複製檔案、易於切換子集、保留來源可追溯性。
  • 缺：每張只看一次 → 比例 = 各 split 自然比例。若需要 imbalance 仍要 sample weight。

E. 推薦組合 ⭐：B + D + Stage 2 微調RECOMMENDED

把 haug 去 augmentation + 新偽標籤 用 multi-path data.yaml 合併，再從 yolo26n best.pt 短期 fine-tune（不是 from scratch）。

具體步驟

  1. 解壓 haug：unzip cleaned_dataset_haug.zip -d /tmp/haug
  2. 過濾 aug 變體：建 symlink 資料夾只連 base 圖（檔名無 _h 後綴），train ~2,750 + val ~222 + test ~112
  3. 建立合併 dataset 根目錄 merged_dataset/ 結構： 
    merged_dataset/
├── data.yaml                          # multi-path
├── haug_base/
│   ├── train/{images,labels}          # symlink (去 aug)
│   ├── val/{images,labels}
│   └── test/{images,labels}
├── new/                                # symlink to yolo26n_ftn_dataset
└── holdout/                            # symlink to 0721TW
  4. data.yaml： 
    path: /home/itemhsu/amtk/lppart/lp/lp_viewer_tool/lp_viewer_output/merged_dataset
train:
  - haug_base/train/images
  - new/images/train
val:
  - haug_base/val/images
  - new/images/val

kpt_shape: [4, 3]
flip_idx: [0, 1, 2, 3]
names:
  0: license_plate
  5. 訓練（從 yolo26n best.pt fine-tune，不是 scratch）： 
    yolo pose train \
  model=yolo26-train-1779339446/best.pt \
  data=merged_dataset/data.yaml \
  epochs=30 imgsz=640 batch=16 \
  lr0=0.001 lrf=0.01 \
  freeze=10 \                           # 保護 backbone
  project=yolo26_finetune \
  name=merged_v1 \
  patience=10 device=0
  6. 獨立評估 holdout（0721TW，356 張）— 證明泛化。

為什麼這套組合最好

  • 不重複學習：去 augmentation 後 haug 不是 4 倍冗餘，新資料不被稀釋。
  • 不破壞既有能力：從 yolo26n best.pt 出發 + freeze backbone + 低 lr → 既有 11,814 已會的不會被打壞。
  • 聚焦弱點：multi-path 讓 sampler 自然把 4,459 新資料（含 692 no_detect、3,946 cell2）暴露給 model。
  • holdout 純粹：0721TW 從未進 train/val，是真實的泛化測試。

3. 風險與緩解

風險緩解
新偽標籤的 corner 雜訊（特別是 weak/no judge consensus 的 cell2）訓練後在 val 看 keypoint loss 趨勢；若異常上升表示偽標籤污染，加入 IoU 篩選
haug 與新資料分布偏差（haug 都是台牌正面，新資料有 BOF 監控視角）multi-path 自然混合；訓練後在 holdout 0721TW 上看效果
haug 中可能有圖與 LPD 重複（selected_plates_429 整合的 418 張）haug 重命名為 hash，無法字串比對；接受少量重複（<3% 機率，影響小）
flip_idx 設 [0,1,2,3] 是 identity 但邏輯上應 [1,0,3,2]（TL↔TR, BR↔BL）沿用 haug 慣例 [0,1,2,3] 維持一致；訓練時關閉 fliplr (fliplr=0.0) 規避
