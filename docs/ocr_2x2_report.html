四格的解讀

🟢 Cell 1: plate-like / same (3,246, 30.4%)

兩條管線都吐出「看起來是車牌」的字串，且字串完全相同。22.9% 可被檔名子字串驗證 — 剩下的 77.1% 多半是 BOF/EP 等無 GT 可比對。

意義：OCR 字串一致 + 形狀對 → 兩個獨立模型給出相同結論，強信心可信。 這 3,246 張可當「OCR pseudo-label」（即使檔名無法驗證）— 是策略 C 的核心戰利品。

🟡 Cell 2: plate-like / different (5,906, 55.3%)

都是車牌形狀但讀出不同字串。Two-step match 率 10.1%，YOLOv26-n 僅 4.0%。當兩者看法不同時，2-step 命中正解的機率是 yn 的 2.5×。

意義：這是「OCR 噪音地帶」。多數失敗源於字元級誤判（B/E、Q/O、O/0），且 2-step OCR 的可信度更高。在做 yolo26n fine-tune 時：
  • 若想用 OCR 字串當 GT (例如訓練 OCR 模型) → 應該採 2-step 字串
  • 若只用 corner 訓練 yolo26n → 這 cell 仍有用，因為位置可能對只是 OCR 讀錯

⚪ Cell 3: not plate-like / same (207, 1.9%)

兩條管線吐出非車牌形狀（過短/過長/含怪字元）但相同字串。8.2% 仍 match — 可能是極短檔名包含此片段，或實際 OCR 漏字。

意義：小型「同錯」群，量少不影響大局。

🔴 Cell 4: not plate-like / different (1,315, 12.3%)

兩者都不像車牌且不同 — 2-step 7.1% / yn 3.0% match 率最低。

意義：多為「偵測抓到非車牌物件」造成的雜訊：招牌、銘牌、車身字樣等。 每個模型對非車牌物件給出隨機性 OCR，所以結果不一致也不像車牌。1,315 張應從訓練集剔除， 否則會教 yolo26n 把雜物當車牌。

關鍵洞見

  1. OCR 字串相同率僅 32.3% — 對於 yolo26n 表現不佳的這 10,674 張，2-step 與 yn 的 OCR 多數不一樣。
  2. OCR 形狀對的比例 85.7% — 即使 yolo26n 在這些桶裡偵測有問題，多數時候它仍能讀出「像車牌」的字串。問題在於讀錯字元，而非完全失敗。
  3. 當 2-step 與 yn 不同調，2-step 命中率高 2.5×（10.1% vs 4.0%）— 證實 Two-step 是更可信的 OCR 來源。
  4. 1,315 張「雙雙非車牌且不同」 — 大概率是偵測器抓錯物件 (招牌/銘牌)。是 yolo26n 訓練要剔除的「污染」樣本。
  5. 排除的「只有 2-step OCR」4,272 張需再拆解（不在 2×2 內，無 yolo OCR 可比）：
    • yolo26n_no_detect（judges 一致同意 corner）：691 張 — 真正可訓練的弱點（有可靠 GT）
    • weak_judge_consensus（judges 自己分歧）：1,010 張 — 無可靠 corner GT
    • no_judge_consensus（judges < 2 偵測）：2,562 張 — 連 GT 都沒
    核心訓練目標只有 691 張，不是 4,272。
