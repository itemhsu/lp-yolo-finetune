9. 重要警語

① Two-step IoU 為 GT 的假設邊界。
Two-step 的 corner 在 yolo26n_no_detect 桶 (judges 一致) 中可靠。 在 Cell 2 的「weak/no judge consensus」子集中，Two-step 自己也可能歪 — 若 YOLO-n 抓到同影像中的另一塊真車牌，硬用 2-step 訓練會把 YOLO-n 教偏。 （已透過 5 桶限制，weak/no judge consensus 仍然可能進入訓練 — 是 trade-off。）
② 多車牌風險未進一步過濾。
本資料集未做 IoU(yolo26n, twostep) ∈ [0.3, 0.8] 篩選 — 因為使用者明確指示「以 2-step 為 GT」。 若訓練後發現 YOLO-n 反而失去多車牌偵測能力，可重跑此腳本加入 IoU 範圍過濾。
③ Holdout 不含同 distribution。
Holdout 全為 0721TW（356 張），其分布可能與 train (BOF 主導 63%) 不同。 Val 集 (BOF 主導) 才能即時監測 overfitting；Holdout 只用於最終評估泛化能力。
④ 樣本權重設定（可選）。由 manifest.csv 的 source 欄分群，建議：
  • no_detect (513 train) → 權重 ×1.5（最直接的弱點）
  • cell2 (3,946 train) → 權重 ×1.0
若用 ultralytics 訓練，可在 dataloader 自定義 sampler 實作；初期可不設、看訓練曲線決定。
